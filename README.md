Proyecto desarrollado durante mis prácticas curriculares en **Balinot Tech Consulting**. Consiste en un ejercicio práctico de maquetación y desarrollo web enfocado en replicar la experiencia visual, estética premium y arquitectura de la web oficial de **Porsche**, combinando **WordPress**, **Stitch**, el entorno **AntiGravity** y flujos de trabajo asistidos por **Inteligencia Artificial**.

---

## 🤖 Integración de IA & Flujo de Trabajo Moderno

Uno de los principales objetivos de este proyecto fue explorar la aceleración del desarrollo frontend mediante herramientas y modelos de IA generativa:

- **Asistencia en Maquetación y Prototipado:** Uso de **Stitch** apoyado en prompts para generar rápidamente bloques de layout limpios y estructuras de interfaz fieles al diseño de Porsche.
- **Generación y Optimización de Código:** Utilización de asistentes de IA para refactorizar CSS/JS, resolver layouts complejos (grids responsivos, efectos visuales tipo scroll/hero) y acelerar la creación de estilos personalizados.
- **Optimización y Curación de Contenidos:** Experimentación con modelos generativos para crear textos ficticios coherentes con el tono de marca y optimizar la preparación de recursos multimedia.
- **Aceleración del Ciclo de Desarrollo:** Reducción drástica del tiempo de implementación desde la concepción del diseño hasta la integración en WordPress gracias a la sinergia entre herramientas de IA y templates en AntiGravity.

## 🛠️ Stack Tecnológico

| Herramienta / Tecnología | Rol en el Proyecto |
| :--- | :--- |
| **WordPress** | CMS para estructurar páginas, gestionar contenido y montar el tema. |
| **Stitch** | Maquetación y diseño asistido de componentes y secciones visuales. |
| **AntiGravity** | Entorno/base de trabajo para la integración y despliegue ágil. |
| **Generative AI Tools** | Soporte en lógica frontend, optimización de hojas de estilo y assets. |
| **HTML5 / CSS3 / JS** | Lógica frontend nativa y personalizaciones a medida para afinar la réplica. |

## ✨ Características de la Réplica

- **Estética Porsche UI:** Cabeceras inmersivas, tipografías estilizadas y estética minimalista de alta gama.
- **Diseño 100% Responsivo:** Adaptación precisa a móviles, tablets y monitores ultrawide.
- **Componentes Modulares:** Bloques reutilizables para carruseles de modelos, especificaciones técnicas y llamadas a la acción (CTAs).
- **Frontend Ligero:** Limpieza de estilos generados para evitar sobrecarga y mejorar el rendimiento de carga.
